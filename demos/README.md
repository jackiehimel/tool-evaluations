# demos

Screen recordings and replay notes for each tool run. Local only: everything in this folder except this file is gitignored.

Layout: `demos/<tool>/` holds the recording(s) and a `SETUP.md` with what the demo was pointed at (target repo, branch, config names, key names — never values). The evidence `MANIFEST.md` for the tool lists each recording's filename so a reader knows it exists and can ask for it.
